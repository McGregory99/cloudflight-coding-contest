# Level 5 - place barriers to trap the wasp
**I/O:** `N`, blank, then per honeycomb: `barrierCount` line + grid rows. Output `N`, blank, then the N modified grids separated by blank lines. `barrierCount` is the guaranteed minimum; several answers are valid (grader validates).
**Approach:** minimum vertex cut between `W` and the outside. Split every `O` cell in -> out with capacity 1 (`W` infinite), edges between neighbours infinite, cells with an out-of-grid neighbour connect to a sink. Max flow (<= 6 augmenting BFS paths, Edmonds-Karp) = min barriers; after the last BFS the cut cells are those whose `in` is reachable in the residual graph but `out` is not. Mark them `X`. Complexity O(6 * E).
**Pitfalls:** only `O` cells may become `X` (never `W`); vertex (not edge) capacities need node splitting; a wasp already trapped gives flow 0 and the grid unchanged. For this input the solver's output even matches the example byte for byte. check.py validates: shape, only O->X changes, count <= barrierCount, wasp trapped (union-find).
